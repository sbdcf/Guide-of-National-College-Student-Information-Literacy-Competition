## 这个比赛是什么

- **母赛事**：中国移动杯·浙江省大学生人工智能竞赛（2026 年为第二届）
- **本赛项**：其中的「AI+信息素养」专项赛（2026 年首次并入母赛事）
- **全国身份**：同时是全国「大学生“AI+信息素养”大赛」的浙江赛区比赛，优胜队晋级全国联赛

## 三级赛制

1. **校赛**：个人，线上客观题，系统随机抽题
2. **省赛**：3 人团队。线上淘汰赛（个人对抗 + 团队对抗）→ 线下决赛（极速对抗 30% + 作品 30% + 现场答辩 40%）
3. **全国联赛**：线下，极速对抗 + 现场答辩

## 几点必须说清的事

- 全程**不收取报名费与参赛费**
- 省赛设一、二、三等奖，获奖比例上限 10% / 15% / 25%
- 学分激励各校自定，**没有任何官方文件承诺“获奖可保研”**
- 2027 年为第三届（按届次顺推），官方文件约在赛年 6–7 月发布
