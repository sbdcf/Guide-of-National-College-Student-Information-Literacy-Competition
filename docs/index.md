# AI+信息素养大赛备考站

中国移动杯·浙江省大学生人工智能竞赛「AI+信息素养」专项赛的备考资料，由学校信息素养部（学生社团）整理。

!!! warning "站点正在搭建中"
    目前只有骨架。参赛指南与题库正在陆续整理上线。

!!! info "先说清楚三件事"
    - 本站是**学生社团**整理的资料，不是学校官方发布，一切以官方通知为准。
    - 比赛名称有两层：母赛事是「浙江省大学生人工智能竞赛」，本赛项是其中的「AI+信息素养」专项赛，同时它还是全国「大学生“AI+信息素养”大赛」的浙江赛区。
    - 高职高专组和本科/研究生组**用的是两套不同平台**，报名时务必进对入口。

## 内容说明

题库里每道题都挂三样东西：**答案、检索依据、核验日期**。因为这套题绝大多数需要真的去数据库里查，答案会随数据库更新失效——没有依据和日期的答案，明年就不能信了。
