# 答题要点

七条，按考场上用得上的顺序排。

## 1. 题目大致分五类

| 类型 | 怎么答 |
| --- | --- |
| 论文数据库检索 | 见[真题讲解](case-study.md)，考专业检索式 |
| 规范与法律法规检索 | 国家法律法规数据库、裁判文书网 |
| 政府时政公告检索 | 政府门户网站站内搜索 |
| 新闻常识辨别 | 可以让 AI 答，但**多开几个对比** |
| 学术工具使用 | 提前摸过一遍软件就行 |

新闻常识类是最适合交给 AI 的一类，因为它不依赖数据库内容。但别只问一个——多开几个 AI 对比回答，不一致的以你自己的判断为准。

## 2. 外文数据库加载慢就先跳

遇到需要访问外文数据库、页面转圈半天的情况：

**先跳过这道题，但把页面留着让它继续加载**，做完别的再回来。客观题可以跳题，别在一个加载条上耗十分钟。

## 3. 输入受限时用图转文

比赛可能会禁用直接的复制粘贴。提前准备图片转文字的工具。

校赛阶段没有额外的反作弊手段，图转文可以直接用 QQ、微信的提取文字功能。省赛请提前装好浏览器插件。

## 4. 提前了解几个规范

至少知道参考文献的标准格式长什么样。这类题不查数据库，纯考你认不认识。

## 5. 多做几遍模拟题

官方模拟题**大部分**有解析——"大部分"是字面意思，有些题的解析栏就写着"无需解释"：

![模拟题解析栏写着"无需解释"](../assets/images/guide/img01.webp)

做模拟题的意义不在刷对错，在于熟悉题型和界面。

## 6. 抓特殊信息，检索式一次别写太死

题干里的**时间、数据库、作者、作者单位、刊物名称**都是关键线索，先圈出来再动手。

- 题干指定了数据库 → 就去那个库查
- 没指定 → 用自己最熟的库
- 一遍没找到 → 先检查检索式和筛选选项，确认无误还是没结果，**换数据库**

## 7. AI 能拿多少分：实测数据

根据 2026 年校赛期间的测试：

- 运气好，AI 能做到 **60 分左右**
- 运气差，**40 分左右**

及格线上下徘徊。所以：

!!! tip "结论"
    在确定你的 AI 能访问论文数据库之前，不要用它搜论文题。

    用 AI 答的每一题，都花点时间查证。
